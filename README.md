# stephennaboth.github.io

Personal academic website for Stephen Naboth, a Ph.D. student in Computational Applied Mathematics and Operations Research at Rice University.

The Astro site contains a one-page academic profile and a separate blog with individual articles.

## Adding the CV

The CV is stored at `public/documents/Stephen_Naboth_Resume.pdf`. The homepage and navigation link directly to that file so visitors can view or download it.

## Local development

```sh
npm run dev
```

## Production build

```sh
npm run build
```

The static site is deployed to GitHub Pages through the existing GitHub Actions workflow.
